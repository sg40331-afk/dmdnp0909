# 문의 구글시트 연동

문의접수 시트:
https://docs.google.com/spreadsheets/d/1CIFb2Voz9fcgndS3kjO-bq9P-XuZYkzWnoxMnL5iQsQ/edit

## 구글에서 한 번 설정

1. 시트에서 확장 프로그램 → Apps Script를 엽니다.
2. 기본 코드를 `integrations/google-sheets/Code.gs` 내용으로 교체합니다.
3. 프로젝트 설정 → 스크립트 속성에 `SHEETS_WEBHOOK_SECRET`을 추가합니다.
   값은 작업폴더의 Git 제외 파일 `.env.sheet-setup.local`에서 확인합니다.
   키는 채팅·Git·시트 셀에 넣지 않습니다.
4. 배포 → 새 배포 → 웹 앱을 선택합니다. 실행 사용자는 본인, 액세스는 모든 사용자로 설정하고 구글 권한을 승인합니다.
   웹앱은 서명 인증을 통과한 쓰기 요청만 받고, 시트 내용 읽기 기능은 제공하지 않습니다.
   시트 자체는 공개 공유하지 않습니다.
5. 배포된 `https://script.google.com/macros/s/.../exec` 주소를 알려주면
   Vercel `dmdnp0909`의 Production·Preview `SHEETS_WEBHOOK_URL`에 설정하고 새 배포합니다.
   보안값은 이미 같은 프로젝트의 서버 환경변수로 저장했습니다.

## 동작

- 전화 상담 버튼은 `010-5201-7977`로 연결합니다.
- 고객 문의는 먼저 Supabase에 저장하고 접수번호를 반환합니다.
- 응답 후 구글시트로 미전송 문의를 최대 3건 전송합니다.
- 실패한 문의는 삭제하지 않고 관리자 → 문의 답변 → 구글시트 미전송 문의 보내기에서 재전송합니다.
- 재전송은 문의ID로 중복을 방지합니다. 대기 문의가 많으면 버튼을 여러 번 눌러 처리합니다.
- 이름·연락처·제품·제목·내용·선택 입력·접수일시·동의일시만 보냅니다.
  비밀번호, 비밀번호 해시, 접수번호, 비공개 첨부파일 링크는 보내지 않습니다.
- 첨부파일과 답변은 홈페이지 관리자에서 확인합니다.
- 시트는 접수 기록의 단방향 사본입니다. 홈페이지에서 문의를 삭제해도 시트 사본은 자동 삭제되지 않으므로
  보관 기간이 지난 기록은 두 곳 모두 정리합니다.

## 확인

구글 웹앱 주소를 연결하기 전에는 실제 시트 수신을 검증할 수 없습니다.
연결 후 테스트 문의가 시트에 한 번만 기록되는지 읽어서 확인하고,
테스트 문의와 시트 행을 모두 삭제합니다.
