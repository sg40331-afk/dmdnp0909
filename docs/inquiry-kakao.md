# 새 제작 문의를 카카오톡 나와의 채팅에 기록

구글시트 웹앱은 변경하지 않습니다. 카카오 발송 전용 Apps Script를 별도로
배포하며, 홈페이지가 새 문의를 저장한 뒤 제품 종류만 서명하여 전송합니다.
고객 이름, 연락처, 제목, 내용, 접수번호, 첨부파일은 카카오에 보내지 않습니다.
이 기능은 채팅방에 기록만 남기며 휴대폰 푸시를 보내지 않습니다.

## 1. 카카오 앱과 별도 Apps Script 준비

1. 카카오디벨로퍼스에서 업무용 앱을 준비하고 카카오 로그인을 켭니다.
   동의항목의 카카오톡 메시지 전송(`talk_message`)을 설정하고
   제품 링크 관리의 웹 도메인에 `https://dmdnp.com`을 등록합니다.
2. Google Apps Script에서 별도 프로젝트를 만들고
   `integrations/kakao-memo/Code.gs`을 적용합니다.
   배포 → 새 배포 → 웹 앱에서 실행 사용자는 본인, 액세스는 모든 사용자를 선택합니다.
   쓰기 요청은 별도의 비밀값으로 서명을 확인합니다. 프로젝트 편집 권한은 공유하지 않습니다.
3. 웹 앱의 `/exec` 주소를 카카오 앱의 REST API 키 설정에서 로그인 리다이렉트 URI로 등록합니다.
   Apps Script의 프로젝트 설정 → 스크립트 속성에 다음 값을 넣습니다.

   - `KAKAO_REDIRECT_URI`: 배포된 카카오 전용 웹 앱 `/exec` 주소
   - `KAKAO_REST_API_KEY`: 앱 REST API 키
   - `KAKAO_CLIENT_SECRET`: 앱에서 클라이언트 시크릿 인증을 사용하는 경우 해당 값
   - `KAKAO_MEMO_WEBHOOK_SECRET`: 구글시트 비밀값과 다른, 무작위 32바이트 이상의 비밀값

## 2. 대표님 계정 연결

1. Apps Script 편집기에서 `createKakaoConsentLink`를 실행합니다.
   실행 로그의 링크는 한 번만 사용하며 10분 동안 유효합니다. 공유하지 않습니다.
2. 링크를 열어 **수신할 카카오 계정**으로 로그인하고 메시지 전송에 동의합니다.
   연결이 완료되면 토큰은 스크립트 속성에 저장됩니다.
3. `sendKakaoTestMemo`를 편집기에서 실행해 해당 계정의 나와의 채팅에서 확인합니다.
4. 트리거 메뉴에서 `maintainKakaoConnection`에 매주 실행되는 시간 기반 트리거를 설정합니다.
   카카오 연결이 철회되거나 토큰이 만료되면 1~3을 다시 진행합니다.

## 3. 홈페이지 활성화

1. Vercel Production에만 `KAKAO_MEMO_WEBHOOK_URL`과
   `KAKAO_MEMO_WEBHOOK_SECRET`을 등록하고 재배포합니다. 비밀값은 카카오
   전용 Apps Script의 동일 이름 속성과 같아야 합니다.
2. 테스트 문의로 카카오 기록과 기존 시트 저장이 모두 되는지 별도로 확인합니다.
   키, 토큰, 비밀값은 채팅이나 Git에 올리지 않습니다.

이 기능은 새 문의에 한해 한 번 발송을 시도합니다. 실패 시 재발송하거나
이전 문의를 소급 발송하지 않으며, 문의 접수와 구글시트 저장은 기존대로 진행됩니다.
